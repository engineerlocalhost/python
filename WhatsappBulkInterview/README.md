Projek automasi whatsapp para kandidat untuk interview

Intruksi :

Buat virtual .env 
    python3 -m venv .venv    
akses .env nya 
    source .venv/bin/activate
Requerment :
    pip install pywhatkit pandas openpyxl
    pip install pyautogui pyperclip

Pad ubuntu 25.04 harus menggunakan xorg
